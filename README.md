# 🎓 IT Academic Tour 2025 — Manila & Beyond

A blog website documenting the IT Academic Tour of Western Mindanao State University (WMSU) from **April 5–12, 2025**, covering Manila, Tagaytay, and Baguio.

## 🗓️ Tour Highlights

| Day | Date | Activity |
|-----|------|----------|
| Day 1 | April 5 | Flight to Manila · Old Manila City Tour (Rizal Park, Intramuros, Manila Cathedral) |
| Day 2 | April 6 | Hytec Power Inc. · OpenText Philippines |
| Day 3 | April 7 | Top Peg Animation & Creative Studio · Teleperformance SE |
| Day 4 | April 8 | MMDA · MicroSourcing Philippines |
| Day 5 | April 9 | Holiday — Tagaytay (People's Park in the Sky, Sky Ranch) |
| Day 6 | April 10 | Midnight travel to Baguio City |
| Day 7 | April 12 | Flight home to Zamboanga City |

## 🛠️ Built With

- **HTML5** — Semantic structure
- **CSS3** — Custom properties, animations, responsive layout
- **Vanilla JavaScript** — Intersection Observer scroll animations, reading progress bar

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/academic-tour.git
   ```
2. Open the project folder in **VS Code**
3. Install the **Live Server** extension (by Ritwick Dey)
4. Click **Go Live** at the bottom right — done!

## 🖼️ Adding Your Own Photos

Replace the Unsplash image URLs in `index.html` with your own photos:

1. Drop your `.jpg` or `.png` files into `assets/images/`
2. Update the `src` attribute in `index.html`:
   ```html
   <!-- Before -->
   <img src="https://images.unsplash.com/..." />

   <!-- After -->
   <img src="assets/images/your-photo.jpg" />
   ```

## 🌐 Deploy to GitHub Pages

1. Go to your repository on GitHub
2. Click **Settings** → **Pages**
3. Under **Source**, select `main` branch → `/ (root)`
4. Click **Save** — your site will be live at:
   ```
   https://YOUR_USERNAME.github.io/academic-tour/
   ```
